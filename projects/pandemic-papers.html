Core systems

The project combines several interaction types in one simulation loop. The engineering challenge is keeping document work, verification feedback and direct object interaction understandable as the player moves through each step.

  • Built a dynamic document-handling and verification flow.
  • Managed complex UI states to keep the current task and its feedback in sync.
  • Implemented custom physics interactions to make handling objects part of play.

Project context

This is a solo Unity/C# project and remains in development. It received second place at the university graduation project presentation. I am using it to develop my experience with simulation-oriented interaction and state-heavy interfaces.
